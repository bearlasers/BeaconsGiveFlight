This is a very simple plugin that gives players flight when they are near a beacon. It prints a message in chat when
flying is applied, and prints another message when it is lost. Players get 10 seconds of slowfalling when they lose flight.

I wrote this for Minecraft 26.2. It will probably work on other 26.x versions. It's a very simple plugin.

The messages are configurable in config.yml in your plugins directory in the BeaconsGiveFlight folder.
You can use <a href=https://docs.papermc.io/adventure/minimessage/>Minimessage</a> formatting to add gradients and stuff.

Reload the plugin using the standard /BeaconsGiveFlight reload if you've changed the config while the server is running.
